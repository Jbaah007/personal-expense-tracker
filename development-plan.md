# Expense Tracker Development Plan

## Milestone 1: Project skeleton
- Create a React frontend and an Express backend.
- Add a simple health check endpoint on the backend.
- Verify both apps can start locally.

## Milestone 2: Database foundation
- Set up SQLite and create an expenses table.
- Add seed data for testing.

## Milestone 3: Expense CRUD API
- Build endpoints to list, create, update, and delete expenses.
- Connect the frontend to the backend.

## Milestone 4: Expense UI
- Add forms for creating and editing expenses.
- Add category selection and delete actions.

## Milestone 5: Summary and visualization
- Show the total spent this month.
- Add a simple spending chart by category.

## Milestone 6: Polish and cleanup
- Improve styling, validation, and error handling.
- Document how to run the app.
