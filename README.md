# Personal Expense Tracker

A clean, responsive web app for tracking personal expenses with local persistence, filtering, sorting, budgeting, and simple analytics.

## Features
- Add, edit, and delete expenses
- Search and filter by category
- Sort by date, amount, or title
- Budget goal tracking
- Local SQLite persistence
- Responsive, polished UI

## Tech Stack
- React + Vite
- Node.js + Express
- SQLite

## Run locally
1. Start the server
   - cd server
   - npm install
   - npm run dev
2. Start the client
   - cd client
   - npm install
   - npm run dev
